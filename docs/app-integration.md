# 主程序接入插件市场（下一阶段）

本仓库目前提供索引与发布流程；DeskLLMPet 主程序还没有「插件市场」UI。本文记录接入约定，避免后续实现时重新设计。

## 1. 目标

设置页在「🧩 插件」下增加「插件市场」标签：

1. 拉取 `https://iskage.github.io/desk-llm-pet-plugins-market/index.json`；
2. 展示名称、版本、作者、说明、标签、大小；
3. 过滤不兼容插件；
4. 用户点击安装 → 下载 → 校验 → 复用现有安装器；
5. 显示「已安装 / 可更新」，但**不自动更新**。

## 2. 主进程接口

建议新增 IPC（只允许设置窗口调用）：

| 通道 | 说明 |
|---|---|
| `plugins:market:list` | 拉取并返回过滤后的市场列表（带缓存） |
| `plugins:market:install` | 下载并安装指定 `id`，返回进度/结果 |

渲染进程只负责展示，网络、校验、解压必须在主进程完成。

## 3. 实现要点

- 索引 URL 与下载域名写在主进程常量中，不接受渲染进程传入任意 URL。
- 下载到 `app.getPath('temp')` 下的独立目录，安装成功后删除。
- 校验：
  - `size` 与实际字节数一致；
  - SHA-256 与索引一致；
  - 交给 `inspectPackage()` 再校验一次包结构与清单。
- 安装复用 `plugin-installer.installPackage()`，保留覆盖/降级确认与「可信来源」勾选。
- 超时、断网、404、校验失败都要有明确错误提示，不能影响已安装插件。
- 市场列表缓存建议 10–30 分钟；手动「刷新」可绕过缓存。
- 不做自动更新；「可更新」只比较 semver。

## 4. 页面结构建议

```text
设置 → 🧩 插件
├── 已安装        # 现有列表：启用/禁用/设置/卸载/打开目录
└── 插件市场      # 新增：搜索、标签筛选、安装/更新
```

市场卡片信息：

- 名称 + 版本 + 作者；
- 一句话说明 + 标签；
- 大小、最低主程序版本；
- 状态：未安装 / 已安装 / 可更新；
- 操作：安装 / 更新 / 查看主页。

## 5. 安全底线

- 插件仍然运行在主进程，市场不是沙箱；
- 只信任固定索引 URL 与本仓库 Releases 域名；
- 强制 SHA-256，不信任索引中的任意下载地址；
- 安装前必须由用户确认；
- 索引格式升级时按 `schemaVersion` 分支处理，未知版本降级为「市场不可用」。

## 6. 实施顺序

1. 主进程实现 `market:list` + 缓存 + 过滤；
2. 设置页加只读市场列表；
3. 实现下载 + 校验 + 安装；
4. 增加「可更新」提示；
5. 最后再考虑签名、举报、下载量等治理功能。

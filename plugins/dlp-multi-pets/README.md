# 多桌宠克隆（dlp-multi-pets）

为 DeskLLMPet 增加「多个桌宠形象共存」的插件，需要 DeskLLMPet 1.2.0 或更高版本。

## 功能

- 右键主桌宠 → **克隆**：创建一个新的透明桌宠窗口。
- 右键克隆体 → **删除当前克隆体**：直接关闭该窗口（不是隐藏），释放后台资源。
- 所有桌宠共用主程序的宠物设置与动画池，改设置后所有克隆体一起变化。
- 主桌宠始终保留；如果主桌宠被隐藏，最后一个克隆体不允许删除，避免一个桌宠都不显示。

## 安装

1. 从插件市场的 Release 下载 `dlp-multi-pets-1.0.0.dlmpet`；
2. 打开 DeskLLMPet → **设置 → 🧩 插件** → 「选择插件包」，选中该文件；
3. 安装后右键主桌宠，菜单里会出现「克隆」。

> 插件市场地址：<https://github.com/isKage/desk-llm-pet-plugins-market>
>
> 本地开发时，在插件市场仓库根目录运行
> `npm run pack -- plugins/dlp-multi-pets`，产物在 `dist/`。

## 说明

- 克隆体不写入单独的配置；它们读取主程序 `userData/config.json` 中的 `pet` 和 `animations`。
- 克隆窗口的尺寸/透明度由主进程根据主程序设置同步；动画、裁剪、偏移由插件渲染进程同步。
- 克隆体不保存到磁盘，重启应用后只保留主桌宠。
- 插件只读取本体 `assets/` 下的动画，不复制素材。
